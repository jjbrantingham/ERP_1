## Prerequisites
- .NET 9.0 SDK
- SQL Server 2022
- Node.js (for Tailwind CSS)

## Getting Started

1. Clone the repository
2. Update connection string in appsettings.json
3. Run migrations: `dotnet ef database update`
4. Run application: `dotnet run --project src/ERP.Web`
